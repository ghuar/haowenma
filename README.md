# 好问吗 · 提问结构优化器

一个面向大学生的 AI 提示词结构诊断与优化工具。

把准备发给 AI 的话贴进去，30 秒告诉你结构缺哪一块，并直接还你一版能用的。

## 在线使用

部署于 GitHub Pages：https://【用户名】.github.io/haowenma/

也可以直接下载 `index.html`，双击用浏览器打开——无需联网、无需配置、不需要后端。

## 它做什么

| 模块 | 说明 |
| --- | --- |
| 测试判断 | 五维打分（角色、目标、约束、格式、背景）＋结构类型标签，给出缺哪一项、为什么缺 |
| 优化思路 | 逐条解释这一项为什么重要，只讲这一条，不上课 |
| 一键优化 | 直接给可复制的成品，新增部分高亮，保留用户原意 |
| 我的提问本 | 同一条任务多版对比、结构分走势，可导出 CSV |

## 评分怎么做的

每项 20 分，满分 100，分三档：明确 20 / 部分 10 / 缺失 0。

- **规则层**：关键词库、正则、结构启发式判断，负责"有没有"。结果稳定、可复现。
- **模型层**：判断目标是否单一、约束是否自相矛盾，负责"好不好"。（当前版本默认不接入，离线可用。）

诊断页的每条判定都会引用用户原话片段并高亮，判定依据是可追溯的。

## 三条边界

1. 不代写正文——不生成作业、论文、报告
2. 不做通用聊天助手
3. 不做 AI 痕迹检测

## 技术说明

单文件 HTML，原生 JavaScript，无框架、无构建、无外部依赖。雷达图用 Canvas 手绘，记录存于浏览器 localStorage，不上传任何服务器。
